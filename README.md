# Consultor Lliga Catalana

Aplicación web para consultar los resultados de jugadores en la Lliga Catalana de Escacs.

## Cómo ejecutar

1.  Navega a la carpeta del proyecto: `c:\Papa\Antigravity\LligaEquipo`
2.  Haz doble clic en el archivo `index.html` para abrirlo en tu navegador web predeterminado.

## Uso

1.  **Modo Demo**: Haz clic en el botón "Demo" para cargar datos de prueba instantáneamente y verificar el diseño.
2.  **Modo Real**: Selecciona el año e introduce un ID de club válido.
    *   *Nota*: Debido a restricciones de seguridad del navegador (CORS), es probable que la consulta directa a la web de la FCE falle si no se utiliza una extensión de navegador para desactivar CORS o un proxy local. La aplicación intenta usar un proxy público, pero su disponibilidad no está garantizada.

## Tecnologías

*   HTML5
*   Tailwind CSS (CDN)
*   Vanilla JavaScript
